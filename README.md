# 이지 네비 스타터 (Easy Navi Starter)

## 프로젝트 목적
차량 USB 전원 연결을 감지해 사용자가 지정한 Android 내비게이션 앱을 자동 실행하고, 전원 해제 시 후속 동작을 처리하는 앱입니다.

## 개발 환경
- 저장소: `ryoobach/Easy_Navi_Starter`
- 기본 브랜치: `main`
- 플랫폼: Android
- 언어: Kotlin
- 빌드: Gradle / GitHub Actions
- 테스트 기기 후보: Poco phone 또는 Samsung Galaxy S22 Ultra
- Galaxy S26 Ultra는 일상용 기기로 유지하며 내비게이션 전용 테스트 기기로 사용하지 않습니다.

## 확정 요구사항
1. 사용자가 설정한 내비게이션 앱을 자동 실행합니다.
2. 차량 USB 전원 연결을 시동 감지 신호로 우선 활용합니다.
3. 차량 전원 해제 시 내비게이션 종료 및 화면 끄기를 검토합니다.
4. 앱 설정과 지정 내비게이션 앱은 재부팅 후에도 유지합니다.
5. 재부팅 후 이전 내비게이션 상태 복원 여부를 사용자에게 묻는 흐름을 구현합니다.
6. 앱별 공개 딥링크/인텐트 등 지원되는 방법으로만 상태 복원을 시도합니다.

## Android 기술 제약
- 일반 앱은 휴대폰 완전 전원 OFF 상태에서 차량 전원 변화를 감지하거나 기기를 켤 수 없습니다.
- Android는 백그라운드에서 다른 앱 화면을 임의로 여는 동작을 제한할 수 있습니다. USB 연결/부팅 이벤트 수신과 내비게이션 자동 실행은 실기기별 검증이 필요합니다.
- 일반 앱 권한만으로 다른 앱을 강제 종료하거나 화면을 끄는 기능은 보장되지 않습니다.
- USB 해제만으로 차량 시동 OFF라고 단정하면 일반 충전기 분리에도 반응할 수 있습니다. 차량 충전기 구분 및 지연 설정을 추후 설계합니다.
