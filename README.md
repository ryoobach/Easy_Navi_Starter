# 이지 네비 스타터 (Easy Navi Starter)

## 프로젝트 목적
차량 전원 상태를 감지해 Android 스마트폰에서 사용자가 지정한 내비게이션 앱을 자동 실행하고, 차량 전원이 해제되면 내비게이션 종료 및 화면 끄기를 처리하는 앱을 만든다.

## 대상 환경
- 우선 대상 기기: Samsung Galaxy S26 Ultra
- 플랫폼: Android
- 저장소: `ryoobach/Easy_Navi_Starter`
- 기본 브랜치: `main`

## 확정 요구사항
1. 사용자가 설정한 내비게이션 앱을 자동 실행한다.
2. 차량 USB 전원 연결을 차량 시동 감지 신호로 우선 활용한다.
3. 차량 전원이 감지되면 내비게이션 앱을 실행한다.
4. 차량 전원 해제가 감지되면 내비게이션 종료 및 화면 끄기를 수행한다.
5. 앱 설정과 지정 내비게이션 앱은 재부팅 후에도 유지한다.
6. 종료 전 내비게이션 상태를 기록할 수 있는 범위에서 저장한다.
7. 다음 부팅 시 사용자에게 이전 내비게이션 화면 복원을 시도할지 묻는다.
   - 예: 이전 상태 복원 시도
   - 아니오: 내비게이션 기본 화면 실행

## Android 기술 제약 및 설계 원칙
- 앱이 스마트폰의 완전 전원 OFF 상태에서 차량 전원 변화를 감지하거나, 일반 앱 권한만으로 전원을 켜는 것은 보장할 수 없다.
- 따라서 1차 구현은 스마트폰이 켜져 있고 대기 중인 상태를 전제로 한다.
- USB 전원 연결/해제 이벤트를 감지하되, 실제 차량 환경에서 기기별 동작을 검증한다.
- USB 해제만으로 차량 시동 OFF라고 단정하면 집/사무실 충전기 분리에도 오작동할 수 있다. 차량 충전기 구분 또는 사용자 설정을 설계한다.
- 다른 앱의 내부 화면/경로 상태를 임의로 읽거나 복원할 수 있다고 가정하지 않는다. 복원은 내비 앱이 제공하는 딥링크, 인텐트, 최근 상태 유지 기능 등 공개적으로 지원되는 수단을 우선 사용한다.
- 화면 잠금, 백그라운드 실행, 배터리 최적화, 자동 시작 등 Android 및 제조사 정책에 따른 권한·사용자 설정을 명확히 안내한다.

## 아직 결정할 사항
- 사용할 내비게이션 앱과 지원할 앱 목록
- 차량 USB 전원 감지 방식 및 차량/일반 충전 구분 방식
- 차량 전원 해제 후 내비게이션 종료까지의 대기 시간
- 화면 끄기 방식과 필요한 접근성/기기 관리자 권한 여부
- 이전 상태 복원 시 내비 앱별로 지원할 수 있는 범위
