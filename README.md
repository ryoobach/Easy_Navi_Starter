# 이지 네비 스타터 (Easy Navi Starter)

## 프로젝트 목적
차량 USB 전원 연결을 감지해 사용자가 선택한 Android 내비게이션 앱의 실행을 보조하는 앱입니다.

## 개발 환경
- 저장소: `ryoobach/Easy_Navi_Starter`
- 기본 브랜치: `main`
- 플랫폼: Android
- 언어: Kotlin
- 빌드: Gradle / GitHub Actions

## 0.2.8 변경 사항
- 앱 버전: 0.2.8 (versionCode 10)
- 최신 티맵 공식 패키지명 `com.skt.tmap.ku` 적용
- 기존 `com.skt.tmap`으로 저장된 티맵 선택값 자동 이전
- 티맵 실행 시 현재 및 구형 패키지명 모두 확인
- [네비 추가] 앱 검색에서 TMAP 영문 표기도 인식

## 0.2.7 변경 사항
- 앱 버전: 0.2.7 (versionCode 9)
- [네비 추가]는 기기에 설치된 한국 내비게이션 앱만 검색
- 설치된 내비 앱이 없으면 안내 메시지 표시
- 체크한 앱만 네비 항목 리스트에 등록하며, 체크 즉시 실행하지 않음
- 네비 항목 리스트에서 선택 후 [설정 저장]을 누르면 선택한 앱을 실행
- 추가한 앱 목록과 선택 상태를 저장해 다음 실행에도 유지

## 0.2.4 변경 사항
- 앱 버전: 0.2.4 (versionCode 6)
- 앱 식별자 유지: `com.ryoobach.easynavistarter`
- APK는 고정된 Release 서명키로만 빌드
- 서명키가 설정되지 않으면 빌드를 중단하며 임시 Debug 서명 APK를 만들지 않음
- APK의 앱 ID, 버전, 서명 인증서 지문을 빌드 후 검증
- APK와 압축 파일 이름에 버전 번호 포함

## 앱 업데이트와 서명키 관리
Android는 기존 앱과 새 APK의 서명 인증서가 같아야 삭제 없이 업데이트할 수 있습니다. 앱 ID가 같고 versionCode가 높아도 서명 인증서가 다르면 업데이트가 거부됩니다.

이전 빌드 기록을 확인한 결과, 임시 Debug 서명 APK들은 빌드마다 서로 다른 인증서 지문을 사용했습니다. 예를 들어 과거 빌드들의 SHA-256 지문이 서로 달랐습니다. GitHub 임시 빌드 환경에서 생성된 Debug 개인키는 보존되지 않아, 과거 설치본의 서명키를 복원할 수 없습니다. 따라서 과거 임시 Debug 서명본은 새로 만든 고정 Release 키로 바로 업데이트할 수 없으며, 해당 설치본은 최초 1회 제거 후 새 앱을 설치해야 합니다.

0.2.4부터는 새로 만든 고정 Release 키를 사용합니다. 이 키를 등록한 뒤 설치한 버전부터는 같은 키를 계속 사용하므로 이후 버전은 앱을 삭제하지 않고 업데이트할 수 있습니다. 키를 분실하거나 교체하면 다시 업데이트 문제가 발생할 수 있으므로 안전하게 백업해야 합니다.

### GitHub 저장소 비밀값
GitHub 저장소 Settings → Secrets and variables → Actions에 다음 4개 값을 등록해야 합니다.
- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

서명키 파일과 각 비밀값은 저장소에 올리지 않습니다. 서명키 설정 안내 압축 파일은 별도로 전달합니다.

## 빌드 검증
GitHub Actions는 다음 항목을 확인한 뒤 APK를 업로드합니다.
1. 앱 ID가 `com.ryoobach.easynavistarter`인지 확인
2. APK 내부의 `versionName`, `versionCode`가 Gradle 설정과 일치하는지 확인
3. APK 서명 인증서 SHA-256 지문이 고정 Release 키의 지문과 일치하는지 확인
4. 버전 번호가 포함된 이름으로 APK 아티팩트 생성

## 확정 요구사항 및 기술 제약
1. 기본 내비게이션 항목은 티맵, 네이버 지도, 카카오맵을 표시합니다.
2. [네비 추가] 목록에는 설치된 한국 내비게이션 앱만 표시하며, 다중 체크 후 네비 항목 리스트에 추가합니다.
3. 네비 항목 리스트에서 앱을 선택하고 [설정 저장]을 눌렀을 때만 선택한 내비게이션 앱을 실행합니다.
4. 저장한 내비게이션 선택과 추가한 앱 목록은 재실행 후에도 유지합니다.
5. 기기 시작 시 저장된 내비게이션 자동 실행을 기본 동작으로 합니다.
6. 일반 Android 앱은 다른 앱을 강제로 종료하거나 휴대폰 전원을 완전히 끌 수 없습니다.
7. USB 해제만으로 차량 시동 종료라고 단정할 수 없습니다. 차량 충전기 구분 및 지연 처리, 화면 제어는 실기기 검증이 필요합니다.
8. Android 백그라운드 실행 제한으로 자동 실행은 기기와 OS별 검증이 필요합니다.
